# Installazione su Chrome

1. Apri `chrome://extensions`.
2. Attiva **Modalità sviluppatore**.
3. Premi **Carica estensione non pacchettizzata**.
4. Seleziona questa cartella: `classic-value-extension`.
5. Ricarica Auction Simulator.

L'estensione serve solo sul computer dell'amministratore. Nel form del lotto comparirà lo stato **Estensione collegata**: il pulsante apre Classic.com, seleziona la vista a un anno, legge `Avg` e riporta il valore nell'app.
